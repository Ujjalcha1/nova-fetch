## About

Nova Fetch is a modern desktop downloader with a beautiful interface, fast downloads, queue management, resume support and more. This repository contains the website that promotes the application, hosts the Windows installer, and provides release notes, FAQ, support and legal pages.

- **Product site:** <https://novafetch.app>
- **Supported platforms:** Windows 10 / 11 (x64)
- **Current app version:** v1.0.0
- **Price:** Free — no ads, no tracking, no bundled software
- **Creator:** Ujjal Chatterjee

## What the site showcases

The single-page landing experience (`/`) is composed of:

- **Hero** — animated headline (GSAP SplitText), capability badges (4K video, batch downloads, MP3 audio, subtitles, no ads) and a download call-to-action
- **Why Nova Fetch** — six value cards: blazing fast, 100% safe, one-click download, modern UI, lightweight, always free
- **Features** — high-speed multi-threaded downloads, resume support, smart queue, batch downloads, secure downloads, clean interface
- **Showcase** — marketing stats, a 3-step workflow (paste a link → choose quality → download), platform/security cards, and a Nova Fetch vs. browser vs. mobile comparison table
- **CTA** — download prompt with release notes link
- **FAQ** — accordion of frequently asked questions
- **Footer** — quick links, legal pages and social links

## Getting Started

**Prerequisites:** [Node.js](https://nodejs.org) 20.9 or newer (Next.js 16 requirement) and npm.

```bash

npm install

# Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Download & Release Flow

The site treats the Windows installer as a drop-in asset — shipping a new build requires no code changes:

1. **`src/lib/downloads.ts`** is the single source of truth for installer metadata: filename (`NovaFetch-Setup.exe`), download URL (`/downloads/windows/NovaFetch-Setup.exe`), app version (`v1.0.0`), platform (`Windows 10 / 11`), architecture (`x64`) and the release-notes URL (`/changelog`). All download buttons across the site read from this module.
2. **`public/downloads/windows/NovaFetch-Setup.exe`** is the installer binary served at the download URL. To ship a new build, replace this file with the new installer.
3. **`src/lib/installer-size.ts`** (server-only, uses `node:fs`) reads the installer size from disk and formats it as MB for the download card. It falls back to `-- MB` when the file is missing or empty.
4. **`src/data/release-notes.ts`** holds the release notes rendered on both `/download` and `/changelog`.
5. **`update.json`** at the repo root is the desktop app's update manifest: `latestVersion: 1.0.0`, `minimumSupportedVersion: 1.0.0`, `forceUpdate: true` and release notes. It is not referenced by the website source.

## SEO & Metadata

- **Centralized site config** — `src/lib/site.ts` (`siteConfig`) holds the name, title, description, URL, creator, support email and keywords used across the site.
- **Page metadata** — a default title (`Nova Fetch - Fast, Modern & Secure Downloader`) with the template `%s | Nova Fetch`, description, keywords, authors, Open Graph tags and a Twitter `summary_large_image` card are defined in `src/app/layout.tsx`.
- **Structured data** — a `SoftwareApplication` JSON-LD block (category `MultimediaApplication`, OS `Windows 10/11`, price `$0`, author, support contact) is injected in the root layout.
- **PWA manifest** — `src/app/manifest.ts` (standalone display, theme color `#7c3aed`).
- **robots.txt & sitemap** — `src/app/robots.ts` allows all crawlers and points to `/sitemap.xml`; `src/app/sitemap.ts` lists all 9 public pages.
- **Open Graph image** — `src/app/opengraph-image.tsx` generates a 1200×630 PNG at request time via `next/og`, embedding the logo from disk with a text-only fallback.
- **Security headers** — `next.config.ts` sets `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin` and disables the `X-Powered-By` header.

## ReactBits Effects

Three effects from [ReactBits](https://reactbits.dev) (registered in `components.json` under the `@react-bits` registry) are used:

- **`Aurora`** — a WebGL shader-based animated aurora background (`ogl` renderer + simplex noise), rendered fixed full-screen behind all page content in the root layout.
- **`SplitText`** — GSAP SplitText with ScrollTrigger for a staggered character reveal, used on the hero headline.
- **`Spotlight`** — a cursor-following radial gradient spotlight that tracks the mouse across the page.

## Notes

- The installer at `public/downloads/windows/NovaFetch-Setup.exe` is currently a **placeholder** (see `public/downloads/windows/README.txt`) — place the real installer there before going live.
- `public/logos/` is empty; `logo.png` is referenced by the metadata, manifest and Open Graph image generator.
- `swr` is declared in `package.json` but is not referenced in the source code.
- No lockfile is committed, so dependencies resolve from the ranges declared in `package.json`.
- This repository does not include a `LICENSE` file; no license is specified.
